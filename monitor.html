Position monitor

A tiny Python script that runs on your bot's computer. While you have an open option position, it sends a small tick to your own bot's webhook about once a minute during US market hours (9:30 AM–4:00 PM ET, weekdays). Each tick wakes your bot, which quotes the position through your own broker connection and applies the stop and trims from your own BOT_PROFILE.

The script never connects to a broker, never places orders, and ships with no keys. It only uses the settings you give it.

Download aispy-monitor.py

What it needs from your setup

  • AISPY_WEBHOOK_URL: your bot's webhook URL (https). Required.
  • AISPY_WEBHOOK_KEY or AISPY_WEBHOOK_KEY_FILE: your bot's webhook key, or a file holding it. Required.
  • AISPY_POSITION_FILE: a JSON file your bot writes when it opens a trade. Ticks are sent only while it contains "status": "open". Default: ~/aispy-monitor/open_position.json.
  • AISPY_BOT_PROFILE: the path to your BOT_PROFILE file. It's sent with each tick so your bot knows which rules to apply. Optional.
  • AISPY_INTERVAL: seconds between ticks. Default 60, minimum 15. Optional.

You can set these as environment variables or as KEY=value lines in ~/aispy-monitor/config.env. Your broker connection (for example Robinhood Agentic) stays inside your bot; the script never sees it.

Install (instructions for your Grok Bot)

Paste this to your bot:

Set up the AISPYALERTS position monitor on your computer:
1. mkdir -p ~/aispy-monitor && curl -fsSL https://aispyalerts.com/monitor/aispy-monitor.py -o ~/aispy-monitor/aispy-monitor.py
2. Create ~/aispy-monitor/config.env (chmod 600) with:
   AISPY_WEBHOOK_URL=<your routine's webhook URL>
   AISPY_WEBHOOK_KEY_FILE=<path to a file holding the webhook key>
   AISPY_POSITION_FILE=<where you write the open-position JSON>
   AISPY_BOT_PROFILE=<path to my BOT_PROFILE>
   Never print the key or paste it into chat.
3. Run: python3 ~/aispy-monitor/aispy-monitor.py check   (it must show no errors)
4. Run: python3 ~/aispy-monitor/aispy-monitor.py once    (one test tick; ignore it when it arrives, since it has "test": true)
5. Start it in the background: nohup python3 ~/aispy-monitor/aispy-monitor.py run >/dev/null 2>&1 &
6. When you open a position, write {"status":"open", ...} to the position file and run "aispy-monitor.py arm".
   When you're flat, set "status":"closed" (or delete the file) and run "aispy-monitor.py disarm".
7. On each price.tick, quote the open position through my broker connection and enforce the stop and trims in my BOT_PROFILE.

Commands

  • run: start the loop.
  • arm and disarm: turn ticks on or off.
  • check: validate the config, with the key masked.
  • once: send one test tick.

The log is written to ~/aispy-monitor/monitor.log.
